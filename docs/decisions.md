# decisions.md — 고른 결정

개발 규격서(결정 카드판 v2.0)의 카드마다 무엇을 골랐는지 적는다. 바꾸려면 이 표를 먼저 고치고 코드를 맞춘다.
날짜: 2026-10-23 (1차 풀체인지)

## 요구

| 카드 | 고른 것 |
|---|---|
| 범위 | 1차: 일기·푸시·해답의 책·소원 쿠폰·매출(버튼). 2차 이사 매물, 3차 주식 분석은 따로 |
| 사용자 | 부부 두 명. 관리자 = 남편 |
| 기기 | 둘 다 아이폰, 홈 화면에 추가한 웹앱. 푸시는 iOS 16.4 이상 |
| 시간 | 모든 날짜·마감은 한국 시각(Asia/Seoul) |

## 스택·구조

| 카드 | 고른 것 |
|---|---|
| STK 서버·화면 | Next.js 16 App Router 풀스택, TypeScript |
| STK 배포 | Vercel Hobby |
| STK DB·로그인 | Supabase (Postgres, Auth). 운영 DB 하나 |
| STK 예약 작업 | Supabase Cron(pg_cron + pg_net) → Next.js 발송 주소. Vercel 무료 Cron 은 ±59분이라 쓰지 않는다 |
| DIR | `src/app` 은 라우트만, 기능은 `src/features/<기능>/`, 공통은 `src/shared/` |
| 캐시 | `cacheComponents` 끔. 모든 화면은 요청마다 서버에서 그린다 |

## 화면

| 카드 | 고른 것 |
|---|---|
| UI 부품 | shadcn/ui (`src/shared/ui`), Tailwind 4 + CSS 변수 토큰 |
| 테마 | 라이트만 |
| 말투 | 「~했어요 / ~해 주세요」 |
| 밀도 | 모바일, 여유 |
| 규칙 문서 | `docs/design.md` |

## 통신·판정

| 카드 | 고른 것 |
|---|---|
| API 통신 | 브라우저는 DB 에 직접 붙지 않는다. 읽기는 서버 컴포넌트, 쓰기는 서버 액션. 사용자 세션으로 DB 에 붙고 DB 규칙(RLS)이 한 번 더 막는다 |
| 실시간 | 없음. 앱으로 돌아오면 새로 그린다 |
| 서버 결과 모양 | `{ ok: true, data }` 또는 `{ ok: false, code }` 하나 |
| 거절 문구 | 화면 쪽 문구 대장 `src/shared/messages.ts` 가 code 로 찾는다 |
| 판정 위치 | 열림·마감·쉬는 날·관리자 판정은 DB 함수. 화면은 결과만 그린다 |
| 못 하는 것 표시 | 잠긴 모양 + 누르면 이유 한 줄 |

## 동시성·정합성

| 카드 | 고른 것 |
|---|---|
| 같은 행 동시 수정 | 마지막 저장이 이긴다(행마다 쓰는 사람이 한 명) |
| 두 번 누르기 | 고유키(일기: 날짜+사람, 답장: 일기)와 상태 조건부 수정(쿠폰)으로 한 번만 반영 |
| 알림 중복 | 발송 기록 표 고유키(종류·날짜·받는 사람·대상)로 한 번만 보낸다 |
| 즉시 알림 | 저장이 끝난 뒤 보낸다. 알림이 실패해도 저장은 남는다 |

## DB

| 카드 | 고른 것 |
|---|---|
| 기본키 | `id bigint generated by default as identity` |
| 표 이름 | 단수 영어 snake_case (`diary_entry`) |
| 칸 순서 | 공통 4칸(`created_at`, `created_by`, `updated_at`, `updated_by`) → PK → UK → FK → 나머지 |
| 공통 4칸 | 트리거가 자동으로 채운다. `created_by`·`updated_by` 가 비어 있으면 시스템(예약 발송)이 쓴 것 |
| 참거짓 | `is_` 로 시작하는 boolean |
| 값 목록 | CHECK 제약으로 DB 가 막는다 |
| 시각·날짜 | 시각은 `timestamptz`, 하루 단위는 한국 날짜 `date` 칸을 따로 |
| 외부 원문 | `if_` 표에 jsonb 로 받고 우리 표로 옮긴다 (1차: 푸시 구독) |
| 수정 이력 | 남기지 않는다 |
| 제약 이름 | `<표>_<칸>_uk`, `<표>_<칸>_fk`, `<표>_<칸>_ck` |
| FK | 모든 참조에 건다 |
| 마이그레이션 | Supabase CLI 타임스탬프 파일 (`supabase/migrations/`). 0001~0010 은 옛 가계부 이력이라 남긴다 |
| Data API 노출 | 새 표마다 `authenticated` 에 필요한 권한만 GRANT + RLS |

## 로그인·권한

| 카드 | 고른 것 |
|---|---|
| 로그인 | 이메일+비밀번호, 가입 없음. 아이디만 쓰면 `@home.local` 을 붙인다(옛 앱과 같음) |
| 세션 | `@supabase/ssr` 쿠키 세션, `src/proxy.ts` 가 갱신 |
| 역할 | `member` 표(남편/아내, 관리자 여부). `user_metadata` 는 쓰지 않는다 |
| 서버 액션 보호 | 액션마다 첫 줄에 `requireMember()` 하나 |
