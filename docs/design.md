# design.md — 화면 규칙

이 앱의 모든 화면은 이 규칙을 따른다. 새 화면·부품을 만들기 전에 읽는다.
값(색·간격)은 `src/app/globals.css` 의 토큰에만 있다. 여기는 규칙만 적는다.

## 1. 기기와 모양

- 대상: 아이폰, 홈 화면에 추가한 웹앱(standalone). 기준 폭 390px, 최소 360px.
- 라이트만 쓴다. 다크 모드는 없다(`.dark` 클래스를 붙이지 않는다).
- 분위기: 아이폰 기본 앱처럼 깔끔하게 — 연회색 바탕, 테두리·그림자 없는 흰 카드, 포인트 색은 밤색 하나.
- 한 화면 = 위 제목 줄 + 본문 + 아래 탭(기록 · 목록 · 분석 · 더보기). 아래 탭 화면은 큰 제목, 하위 화면(호실, 계정)은 뒤로 가기 + 작은 제목.
- 아래 탭과 제목 줄은 아이폰 안전 영역(`env(safe-area-inset-*)`)만큼 띄운다.

## 2. 색

| 토큰 | 쓰는 곳 |
|---|---|
| `background` | 화면 바탕(연회색). 아이폰 상단 색·앱 설치 바탕색과 같은 값 |
| `card` | 내용 묶음 바탕(흰색). 테두리·그림자 없이 바탕색과의 차이로만 나눈다 |
| `muted`(칠) | 카드 안에 놓인 작은 상자 |
| `primary` | 밤색. 화면마다 가장 중요한 버튼 하나, 선택된 탭 |
| `muted` / `muted-foreground` | 보조 글, 날짜, 안내 |
| `destructive` | 지우기 확인 버튼만 |

- 임의 색(`#hex`, `text-red-500` 같은 Tailwind 기본 팔레트)을 쓰지 않는다. 필요하면 토큰을 더하고 이 표에 적는다.

## 3. 글자와 간격

- 글꼴: 프리텐다드(npm `pretendard`, 앱이 직접 내려줌). 본문 16px(아이폰이 입력칸을 확대하지 않는 크기), 보조 14px, 큰 제목 32px(아래 탭 화면), 작은 제목 20px(하위 화면), 큰 숫자 28px.
- 간격은 넉넉하게(밀도 「여유」): 묶음 안 `gap-3`, 묶음 사이 `gap-6`, 화면 좌우 여백 `px-4`.
- 누르는 것은 높이 44px 이상(`h-11`).
- 모서리는 토큰 `--radius`(12px) 하나에서 나온 `rounded-lg`·`rounded-xl` 만 쓴다.
- 앱 아이콘: 밤색 바탕에 버섯 병. 원본 `public/favicon.svg`.

## 4. 부품

- 화면 부품은 `src/shared/ui/`(shadcn) 것을 쓴다. 맨 `<button>`·`<input>` 을 직접 꾸미지 않는다.
- 기능 전용 조각은 `src/features/<기능>/components/` 에 둔다. 두 기능 이상이 쓰게 되면 `src/shared/` 로 옮긴다.

| 상황 | 부품 |
|---|---|
| 내용 묶음 | `Card` |
| 글 쓰기 | `Textarea`(메모), `Input`(한 줄·숫자) |
| 확인이 필요한 지우기 | `AlertDialog` |
| 저장됨·실행취소 알림 | `sonner` 토스트(화면 아래, 3초) |
| 켜고 끄기 | `Switch` |

## 5. 말투와 문구

- 「~했어요 / ~해 주세요」. 반말·명령형을 쓰지 않는다.
- 모든 거절·오류 문구는 `src/shared/messages.ts` 한 곳에 있다. 화면은 서버가 준 코드로 문구를 찾는다. 화면 코드에 오류 문장을 직접 쓰지 않는다.
- 빈 화면에는 무엇을 하면 되는지 한 줄을 쓴다(예: 「아직 기록이 없어요」).

## 6. 판정 표시

- 권한(회원·관리자) 판정은 서버(DB 함수·RLS)가 한다. 화면은 서버가 준 결과를 그대로 그린다.
- 분석 합계·추이는 표시용 계산이라 `src/features/analysis/stats.ts` 에서 한다.

## 7. 저장 흐름

- 저장 버튼은 누르는 동안 비활성 + 「저장 중…」. 두 번 눌러도 한 번만 저장된다(서버도 막는다).
- 저장이 되면 토스트 「저장했어요」. 실패하면 문구 대장의 문구를 토스트로.
